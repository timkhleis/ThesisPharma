# Pre-outcome amendment: count-only early-recruitment solve

The frozen count-plus-active early-recruitment design was run through its
support and balance stage before any post-treatment outcome was inspected.
It was exactly feasible in 13 of 16 cohorts and infeasible in cohorts 1995,
1998, and 1999.

This amendment activates the count-only variant already considered in P5c:

- retain the early recruitment rule, cohorts, donor support, deal gates,
  weighting scheme, five annual patent-count constraints, inventor
  covariates, and firm covariates unchanged;
- omit the five active-patenting indicators from the entropy constraints;
- report the active-patenting differences as unconstrained diagnostics;
- require all 16 cohorts to pass the same maximum absolute standardized
  difference rule on the variables actually balanced;
- inspect no P6 outcome unless this amended design passes.

Patent count is the primary outcome of this recruitment/lifecycle diagnostic.
The amendment therefore preserves the complete annual trajectory of the
primary outcome while avoiding an infeasible constraint set caused by adding
five deterministic indicators of those same annual counts.
