## Cohort audit: is 1993 included?

Yes, in the amendment worktree. The amendment changes the common cohort support to **1993–2010**. The 1993 cohort is admissible because the locked design only consumes five pre-treatment years, `g-5,...,g-1`; a 1993 deal therefore has 1988–1992 available. The older 1994 lower bound came from a superseded design that used `g-6,...,g-3`.

The amendment's pre-outcome gate reports 524 eligible treated inventors across two 1993 deals. Of these, 103 first appear in 1988. Relative to the older release, the main supported treated mass increases from 27,078 to 27,598, consistent with 520 additional supported treated inventor observations in the final estimand.

1. **Release closure:** integrate and reproduce the existing 1993 Local Match v2 amendment; create one authoritative current release and generated table registry.
2. **Identification closure:** build the repaired-sample CS(2021) package, control-group comparison, anticipation pair, valid timing placebo, and short-window table.
3. **Mechanism closure:** add the TechDrift–quality association and management-transition diagnostic; run the network feasibility gate.
4. **Thesis decision:** decide whether DealSim is reported only as a failed-power test or reopened as explicitly exploratory; separately decide whether defensible selection bounds can be specified.
5. **Writing integration:** update all chapters from generated tables, preserve the Local Match v2/HonestDiD caveats, and remove any analysis promises that remain scientifically unjustified.

No missing analysis was estimated during this audit. This preserves the requested approval boundary and avoids silently changing the locked design or running post-gate DealSim tests.
