# Archived analysis code

These folders contain completed exploratory work retained for transparency.
They do not define the current Local Match v2 pipeline and must not be run to
regenerate headline results.

- `main_did_v1/`: preliminary Callaway--Sant'Anna, matching, and robustness
  explorations that motivated the Local Match v2 design (48 scripts).
- `scratch/`: one-off inspection utilities and diagnostics.

For the current production sequence, see `../../README.md` and the repository
root README.
